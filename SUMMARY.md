## Статус: ✅ ЗАВЕРШЕНО

Реализовано полнофункциональное решение **взаимного TLS (mTLS) соединения** между банком HIТsoff и партнером с проверкой сертификатов через CA.

## Как работает мTLS

```
1. Клиент инициирует соединение
         ↓
2. Сервер отправляет свой сертификат
         ↓
3. Клиент проверяет подпись сертификата с помощью CA
         ↓
4. Сервер требует сертификат от клиента
         ↓
5. Клиент отправляет свой сертификат
         ↓
6. Сервер проверяет подпись сертификата с помощью CA
         ↓
7. Оба доказывают владение приватными ключами
         ↓
8. Устанавливается защищенное соединение
         ↓
9. Все данные передаются в зашифрованном виде
```

## Как использовать

### Запуск демонстрации
```bash
bash scripts/run_demo.sh
```

### Генерирование новых сертификатов
```bash
cd scripts
./generate_certs.sh
```

### Запуск тестирования
```bash
chmod +x TESTING.sh
./TESTING.sh
```

### Использование из curl
```bash
curl --cacert certs/ca-cert.pem \
     --cert certs/client-cert.pem \
     --key certs/client-key.pem \
     https://127.0.0.1:8443/api/validate
```

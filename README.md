Вы работаете в отделении эквайринга банка "HITsoff". Для безопасного соединения с партнерами
вам поручили настроить mTLS соединение.
Для демонстрации вы можете использовать любой ЯП и любой протокол взаимодействия
сервисов. Криптографические библиотеки вам разрешил использовать тимлид,
однако ИБ очень настаивала на том, чтоб вы написали свое корпоративное решение.

Вы можете реализовать это несколькими разными способами:
* Двухстороннее шифрование с использованием симметричного ключа - 7 балла
* Двухстороннее шифрование с использованием двух пар ключей - 10 баллов
* Двухстороннее шифрование с использованием двух пар ключей и проверкой сертификата с помощью CA (цифровая подпись) - 15 баллов

Нельзя реализовать сразу несколько вариантов одновременно.

Сдавая работу, вы должны объяснить как происходит безопасное взаимодействие между банком и партнером
